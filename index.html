SpoilerShield

Hide game spoilers before they reach your screen.

A Chrome extension that removes Grand Theft Auto VI posts, videos, thumbnails, comments and search suggestions from YouTube, Reddit, X, Instagram, TikTok and Google, before they're drawn on screen. Everything runs in your browser: no account, no data collected.

Download SpoilerShield 1.0.0

Zip file, 36 KB · Chrome, Edge, Brave and other Chromium browsers on a computer (not phones)

Install in 2 minutes

  1. Unzip the download. On a Mac, double-click the zip. On Windows, right-click it and choose Extract All. You'll get a folder called spoilershield-1.0.0.
  2. Move that folder somewhere permanent, such as Documents. Chrome loads the extension from this folder every time, so don't delete it.
  3. Open a new tab and go to chrome://extensions. In Edge use edge://extensions, in Brave brave://extensions.
  4. Turn on Developer mode (switch at the top right).
  5. Click Load unpacked and select the spoilershield-1.0.0 folder. Select the folder itself, the one that contains manifest.json.
  6. Reload any YouTube, Reddit, X, Instagram, TikTok or Google tabs that were already open.
  7. Optional: click the puzzle-piece icon in the toolbar and pin SpoilerShield so you can see how much it has hidden.
Chrome may sometimes remind you that you have "developer mode" extensions turned on. That's expected for extensions installed this way. Close the message and SpoilerShield keeps working.

Tips

  • Strict mode (in the toolbar popup) keeps every card hidden until it has been checked, and hides cards with no text to check. Recommended now that the game is out and spoiler titles get vaguer.
  • By default it also hides anything mentioning Lucia, Jason, ending, death or dies, even outside GTA. Turn the "Spoiler words" category off in Keywords & settings if that's too much.
  • Add your own words in Keywords & settings to block other games or shows too.
  • It reads text, not images. A spoiler that exists only inside a thumbnail can get through, though Strict mode hides cards with no text.

Chrome Web Store version

SpoilerShield has been submitted to the Chrome Web Store and is waiting for review. Once it's approved, you can install it from there with one click and get automatic updates. You can then remove this copy from chrome://extensions.
